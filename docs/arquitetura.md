# Guia do projeto · LabX

O LabX é um projeto acadêmico de laboratório de biologia em realidade virtual. Este repositório contém a documentação inicial. A cópia local do Unity precisa ser importada para que o ambiente possa ser aberto e testado.

## Organização após a importação

| Pasta do Unity | O que procurar |
| --- | --- |
| `Assets/` | A cena inicial, scripts de interação, recursos visuais e prefabs. |
| `Packages/` | A lista de pacotes e suas versões. |
| `ProjectSettings/` | Versão do editor e configurações do projeto, incluindo a plataforma quando documentada. |

## Primeira verificação

1. Confira os arquivos necessários no [README](../README.md).
2. Leia a versão indicada em `ProjectSettings/ProjectVersion.txt` e abra o projeto no editor correspondente.
3. Identifique a cena inicial e confira os controles e o hardware suportado antes de registrar as instruções de execução.
